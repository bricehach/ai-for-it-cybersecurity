# Prompting

Cet espace regroupe mes travaux sur la formulation de demandes efficaces à un système d’IA.

## Axes étudiés

- définition claire de l’objectif ;
- contexte utile ;
- contraintes ;
- structure attendue de la réponse ;
- critères de vérification ;
- itération et amélioration du prompt ;
- adaptation au niveau technique de l’interlocuteur.

L’objectif n’est pas de collectionner des « prompts magiques », mais de construire une méthode reproductible.
