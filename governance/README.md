# Gouvernance & IA responsable

Cet espace regroupe les travaux liés à l’intégration responsable de l’IA dans une organisation.

## Thèmes

- gouvernance des usages ;
- validation humaine ;
- gestion des risques ;
- qualité et traçabilité des sources ;
- confidentialité et protection des données ;
- souveraineté numérique ;
- portabilité ;
- dépendance fournisseurs ;
- documentation des décisions et limites.

L’objectif est de relier les possibilités techniques de l’IA aux exigences réelles de sécurité, de conformité et de maîtrise opérationnelle.
