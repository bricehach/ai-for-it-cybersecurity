# Cas d’usage IA pour la cybersécurité

Cet espace documentera des usages défensifs et pédagogiques de l’IA appliquée à la cybersécurité.

## Axes envisagés

- lecture et structuration de logs ;
- analyse d’événements Windows et Sysmon ;
- aide à la compréhension de règles de détection ;
- préparation de scénarios SOC / DFIR ;
- documentation d’incidents et de laboratoires ;
- comparaison d’hypothèses d’analyse ;
- contrôle systématique avant toute utilisation opérationnelle.

Les contenus publiés ici restent orientés **défense, apprentissage, laboratoire et documentation**.
