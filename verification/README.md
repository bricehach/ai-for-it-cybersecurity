# Vérification des réponses IA

Cet espace est consacré au contrôle de la qualité des réponses produites par les systèmes d’IA.

## Points de contrôle

- distinguer faits, hypothèses et interprétations ;
- vérifier les sources lorsqu’elles existent ;
- rechercher les incohérences ;
- tester les commandes et procédures dans un environnement adapté ;
- comparer plusieurs approches lorsque l’enjeu le justifie ;
- documenter les limites et incertitudes ;
- conserver une validation humaine avant utilisation opérationnelle.
