# RAG — Retrieval-Augmented Generation

Cet espace est consacré à l’utilisation de sources maîtrisées pour améliorer la pertinence et la traçabilité des réponses d’un système d’IA.

## Axes de travail

- sélection et qualité des sources ;
- préparation et structuration documentaire ;
- recherche de contexte pertinent ;
- citations et traçabilité ;
- limites du RAG ;
- confidentialité des documents ;
- architectures locales, privées ou souveraines lorsque le contexte le nécessite.
