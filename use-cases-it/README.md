# Cas d’usage IA pour l’IT

Cet espace documentera des usages concrets de l’IA dans les métiers IT.

## Exemples de travaux

- diagnostic Windows et Linux ;
- préparation de procédures techniques ;
- aide à l’analyse de configurations ;
- assistance PowerShell, Python et Bash ;
- documentation d’infrastructures et de laboratoires ;
- génération de check-lists et arbres de décision ;
- comparaison d’approches de dépannage.

Chaque cas d’usage devra préciser le besoin, les données utilisées, la méthode de vérification et les limites observées.
